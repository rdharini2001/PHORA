# Legacy / provenance files

These files are retained to document the development history. They are **not** the recommended entry points.

- `original_paper_notebook.ipynb`: final development notebook supplied for the paper run.
- `original_notebook_cells.py`: cell-export version of the earlier notebook.
- `pyradiomics_reference_extractor.py`: optional PyRadiomics implementation explored during development; the final reported paper results use `src/phora/handcrafted_radiomics.py` instead.
- `original_readme.md`: earlier working notes.

For reproduction, use `notebooks/01_reproduce_paper.ipynb` or `scripts/run_reproduction.py`.
